# Research planning

Use this type when a durable question needs a retained method and evidence. Add the exact question, decision or follow-up the answer will inform, evidence sources, evaluation method, stopping conditions, uncertainty, and the artifact or handoff that will retain findings and provenance.

Separate evidence gathering from any later implementation commitment. Do not present a hypothesis as a Decision, treat source collection as verification, or use this type for an ordinary answer that needs no durable work.
