# Bounded-outcome planning

Use this default when no specialized planning type materially improves the proposal.

Shape one bounded outcome with included and excluded scope, material assumptions, observable acceptance criteria, required verification, real dependencies, and the owner action needed to adopt or persist the work. Decompose only when separate results have meaningful dependency, verification, approval, or execution boundaries.

Do not add methodology dimensions, schedules, estimates, groupings, or repository artifacts merely to make the plan appear complete. Preserve a clearly identified uncertainty when specialization would require an unsupported assumption.
