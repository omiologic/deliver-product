# Phased-project planning

Use this type to coordinate exact related delivery Plan versions across meaningful outcome or dependency horizons. Add each phase's observable exit condition, the Plans it coordinates, cross-plan dependencies, decision points, and evidence needed before the owner advances coordination.

A phased-project proposal is not an executable payload and contains no executable WorkItems of its own. Do not use it merely because one outcome is large; prefer a bounded delivery Plan unless independently approvable or measurable Plans require coordination.
